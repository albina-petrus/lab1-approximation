# Лабораторна робота №1 — Апроксимація функцій методами інтерполяції та МНК

**Виконала:** Петрус Альбіна Андріївна, ІПЗ-2, 4 курс · **Варіант:** 22
**Стек:** HTML5 · CSS3 · JavaScript (ES6+) · Canvas 2D API. Без сторонніх бібліотек.

## Запуск
Відкрийте `index.html` у браузері (Chrome / Edge / Firefox) подвійним кліком. Сервер і встановлення не потрібні.
Тести: `tests.html`.

## Можливості
- Набори точок варіанта 22 (5, «10» — у файлі варіантів 9, 20 точок), ручний ввід з валідацією, перемикання наборів одним кліком.
- Інтерполяційний поліном Лагранжа (класична та барицентрична форми) і форма Ньютона з таблицею поділених різниць.
- МНК ступеня m = 1…4: дизайн-матриця Вандермонда, **QR-розклад Хаусхолдера** (без нормальних рівнянь), нормалізація x ∈ [−1; 1], залишки, SSE / MSE / RMSE / max|r| / R².
- Графіки на власному Canvas-рушії: сітка з підписами, легенда з вимиканням кривих, підказки при наведенні, зона екстраполяції, перемикач «Інтерполяція / МНК / Усі», діаграма залишків.
- **Автомасштабування осей X і Y** (min/max точок і видимих кривих + 10 %), у тому числі на кожному кадрі анімації з плавним наближенням меж.
- Вкладка «Порівняння 5 / 10 / 20»: **6 графіків** (3 — інтерполяція, 3 — МНК) і зведена таблиця метрик.
- Анімації (`requestAnimationFrame`): покрокове додавання вузлів з виділенням активного; «ріст» полінома МНК від y = ȳ і поступова поява залишків; пауза, скидання, швидкість.
- Режим «шум ±2 %» — демонструє ефект Рунге (дані варіанта лежать точно на параболах).

## Структура
```
index.html        інтерфейс
style.css         стилі
tests.html        модульні тести і порівняльні таблиці
js/data.js        набори точок, парсер, шум
js/lagrange.js    Лагранж, барицентрична форма, Ньютон
js/lsq.js         МНК: Вандермонд, QR Хаусхолдера, метрики
js/plot.js        Canvas-рушій, автомасштаб
js/animation.js   анімації
js/main.js        контролер UI
docs/             ТЗ, методологія, ідентифікатори, діаграми (Mermaid + PNG)
report/           звіт, AI Interaction Log (xlsx), скріншоти
```

## Методологія та історія комітів
Полегшена **V-модель**: ТЗ → проєктування → реалізація модулів → модульні тести → тести взаємодії → приймання (звіт). Кожен етап — окремий коміт (`git log --oneline`).
