# Технічне завдання

**Тема:** вебзастосунок для апроксимації функцій методами інтерполяції та МНК.
**Варіант:** 22. **Стек:** HTML5, CSS3, JavaScript (ES6+), Canvas 2D API — без сторонніх бібліотек.

## 1. Вхідні дані
| Набір | Точки | Закон, якому відповідають дані |
|---|---|---|
| 5 точок | (1;1), (2;4), (3;9), (4;16), (5;25) | y = x² |
| «10 точок» (у файлі варіантів — 9) | (0;1), (1;2), (2;4), (3;7), (4;11), (5;16), (6;22), (7;29), (8;37) | y = 0,5x² + 0,5x + 1 |
| 20 точок | x = 0; 0,5; …; 9,5 | y = 0,8x² + 0,2x + 1,5 |

## 2. Функціональні вимоги
- **FR-1.** Вибір набору 5 / 10 / 20 точок одним кліком; ручний ввід точок у форму з валідацією (числа, різні x, 2–30 точок), автоматичне сортування за x.
- **FR-2.** Інтерполяційний поліном Лагранжа; форма Ньютона з таблицею поділених різниць (виведення в інтерфейс).
- **FR-3.** МНК-апроксимація поліномом ступеня m = 1…4: дизайн-матриця, коефіцієнти через QR-розклад Хаусхолдера (нормальні рівняння не використовуються), ŷᵢ, залишки rᵢ = yᵢ − ŷᵢ, метрики SSE, MSE, RMSE, max|r|, R².
- **FR-4.** Графіки: експериментальні точки, крива інтерполяції, крива(і) МНК; діаграма залишків (штрихи, маркери, підписана лінія r = 0); перемикач «Інтерполяція / МНК / Усі».
- **FR-5.** Шість графіків порівняння: інтерполяція та МНК для наборів 5, 10, 20 точок; зведена таблиця метрик.
- **FR-6.** Анімація інтерполяції: покрокове додавання вузлів, плавне оновлення кривої, виділення активного вузла.
- **FR-7.** Анімація МНК: «ріст» полінома від горизонтальної лінії y = ȳ до остаточної кривої, поступова поява відрізків залишків.
- **FR-8.** Автоматичне масштабування осей X і Y (min/max точок і видимих кривих + відступ 10 %), у тому числі на кожному кадрі анімації.
- **FR-9.** Легенда з можливістю приховати криві; підказка при наведенні (координати, ŷ, похибка у вузлі; позначка зони екстраполяції).

## 3. Нефункціональні вимоги
- Без зовнішніх бібліотек для графіків і математики.
- Анімація через `requestAnimationFrame`, плавність ~60 кадрів/с.
- Чітке зображення на High-DPI екранах (`devicePixelRatio`), адаптивне полотно.
- Запуск подвійним кліком по `index.html` без сервера та встановлення.
- Сучасні Chrome, Edge, Firefox.
- Кожний логічний етап — окремий git-коміт.

## 4. Інтерфейс
Двоколонковий макет: ліворуч — панель керування (набір точок, режим, форма полінома, ступінь m, анімація, швидкість), праворуч — основний графік з легендою, діаграма залишків, таблиці метрик і поділених різниць. Окрема вкладка «Порівняння 5 / 10 / 20» з шістьма графіками.

## 5. Обмеження
- Глобальна інтерполяція великого ступеня (20 вузлів) схильна до ефекту Рунге; криві, що виходять за розумні межі, обрізаються областю графіка і не «ламають» масштаб.
- Ступінь МНК не перевищує N − 1.
- За межами [x₀; xₙ] (зона екстраполяції) результати є прогнозом і позначаються кольором.
